# Sauerbraten-VR

[![Sponsor](https://img.shields.io/badge/Sponsor-SgtBilko76-ea4aaa?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/SgtBilko76)


A standalone native port of the classic open-source shooter *Cube 2: Sauerbraten* to Meta Quest and PICO. Built directly on OpenXR, it runs the original engine on-headset with full stereoscopic rendering, room-scale head tracking, and motion controls — no PC or streaming required.

Aiming is decoupled from your head: point the right controller and shoot where you're actually pointing. Move with the left stick, snap-turn with the right, and browse the menus with a laser pointer.

One APK covers both headsets: the controller bindings and OpenXR extensions are picked automatically at startup. The PICO build has not been tested on real hardware yet — reports are very welcome.

## Controls

| Input | Action |
|---|---|
| Right trigger | Fire / select |
| Right stick ←→ | Snap turn |
| Right stick ↑↓ | Switch weapon |
| Right B | Back |
| Left stick | Move & strafe |
| Left trigger | Jump |
| Left Menu | Main menu |
| Left Y | Scoreboard |

## About Sauerbraten

Forked from https://sourceforge.net/p/sauerbraten/code/HEAD/tree/

Cube 2: Sauerbraten is a free multiplayer & singleplayer first person shooter, the successor of the Cube FPS.
Much like the original Cube, the aim of this game is fun, old school deathmatch gameplay and also to allow map/geometry editing to be done cooperatively in-game.

http://sauerbraten.org/
